# ESP32-S3 三轮全向小车横向避障

这是Arduino横向绕障逻辑的ESP-IDF 5.4.4 / VS Code优化版。短按ESP32-S3的BOOT键开始，再按一次停止。

## 接线

| 功能 | ESP32-S3 |
|---|---|
| 红外OUT4 / OUT3 / OUT2 / OUT1 | GPIO7 / 6 / 5 / 4 |
| 左前轮D通道 IN1 / IN2 / PWM | GPIO8 / 9 / 10 |
| STBY | GPIO11 |
| 后轮B通道 IN1 / IN2 / PWM | GPIO12 / 13 / 14 |
| 右前轮A通道 IN1 / IN2 / PWM | GPIO15 / 16 / 17 |
| HC-SR04 TRIG | GPIO18 |
| HC-SR04 ECHO | 经降压后接GPIO21 |
| BOOT启停 | GPIO0 |

HC-SR04使用5V供电，但标准ECHO高电平约为5V，不能直接接ESP32-S3。可用 `1 kΩ + 2 kΩ` 分压：

```text
HC-SR04 ECHO ---- 1 kΩ ----+---- GPIO21
                            |
                           2 kΩ
                            |
                           GND
```

传感器、驱动板与ESP32-S3必须共地。

## 优化后的状态机

1. `IDLE-FORWARD`：左、右前轮按45%和49%的实测比例直行，后轮停止；每30 ms测距一次。
2. 障碍距离不大于9 cm连续出现两次才确认，降低偶发近距离回波误触发；不大于6 cm时单次立即触发，避免确认延迟造成碰撞。
3. `STOP`：立即停车120 ms，让车体稳定。
4. `STRAFE-LEFT`：只驱动后轮横向左移900 ms，离开原黑线并绕到障碍物侧面。
5. `FORWARD-PASS`：按校准后的左右轮比例前进1200 ms，越过障碍物。
6. `STRAFE-RIGHT-FIND-LINE`：只驱动后轮向右移动；至少移动250 ms后，要求中间OUT3或OUT2连续三个控制周期检测到黑线，才认为真正回线。
7. `REACQUIRE-PAUSE`：停车120 ms后重新向前运行。
8. 横向找线超过2600 ms仍未成功，进入 `LINE-SEARCH-TIMEOUT` 并停车，不再盲目移动。

完成一次避障后，必须连续五次测得前方大于15 cm才重新允许触发，防止同一个障碍物反复启动状态机。

## 与旧ESP-IDF版本相比

- 旧版是“减速、后退、原地左/右转”，不能保证回到原黑线；新版按Arduino程序横向绕开，再利用中间红外探头找回黑线。
- 旧版每轮等待三次完整测距中值，制动延迟较大；新版30 ms单次采样，9 cm使用两次确认，6 cm使用紧急单次触发。
- 无回波可能表示前方开阔，因此不直接判故障；ECHO触发前异常高电平或开始后无法回落才累计为故障，连续三次后停车。
- Arduino版任意一个红外探头见黑就结束回线；新版要求中间两个探头之一连续三次见黑，避免外侧探头瞬时扫到黑线就过早结束横移。
- Arduino版默认每次启动只绕一个障碍；新版离开障碍并连续确认前方安全后自动重新布防，可以处理后续障碍。
- 加入BOOT实体按键启停和独立超时停车，烧录后不依赖电脑或Monitor。

## 首次测试

源码默认：

```c
#define ENABLE_MOTOR_OUTPUT 0
```

此时只运行测距、红外读取和状态机日志，GPIO11保持关闭，电机不会转。先烧录并打开Monitor，把障碍物分别放在约5 cm、9 cm和20 cm位置，检查距离与状态变化。

测距和接线确认正确后，把 `ENABLE_MOTOR_OUTPUT` 改为 `1`，重新编译。首次电机测试必须架空小车，确认：

- `IDLE-FORWARD`：两个前轮使车体前进，后轮不转；
- `STRAFE-LEFT`：只有后轮转，车体趋势向左；
- `STRAFE-RIGHT-FIND-LINE`：后轮反向，车体趋势向右；
- 任意状态按BOOT都能停车。

实车横移方向若与上述相反，不要改变全部电机方向，只交换 `strafe_left()` 与 `strafe_right()` 中后轮命令的正负号。
