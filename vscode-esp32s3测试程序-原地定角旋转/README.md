# 原地定角旋转测试

小车上电后保持停止。短按一次 ESP32-S3 的 BOOT 键，小车按设定角度原地旋转并自动停止。旋转期间再次按 BOOT 可以紧急停止；停止后再次按 BOOT 可以重复测试。

程序采用“旋转时间估算角度”的开环控制，没有陀螺仪反馈，因此电池电压、地面摩擦和负载都会影响实际角度，首次使用必须标定。

## 参数位置

打开 `main/main.c`，在文件顶部修改：

- `TARGET_ANGLE_DEG`：目标角度。正数为顺时针，负数为逆时针；默认 `90.0f`。
- `TURN_POWER_PERCENT`：旋转功率，范围 35～100；默认 45%。
- `TURN_MS_PER_DEGREE`：每旋转 1° 所需时间；默认 `8.0f ms/°`，必须根据实车修正。

例如将目标改成逆时针旋转 180°：

```c
#define TARGET_ANGLE_DEG (-180.0f)
```

## 标定方法

先设定目标 90° 并测量实际旋转角度。新参数按下式计算：

`新的 TURN_MS_PER_DEGREE = 当前值 × 90 ÷ 实际角度`

例如当前为 8.0，实际只转了 72°，则新值为 `8.0 × 90 ÷ 72 = 10.0`。功率改变后需要重新标定。

## 接口

- 左前轮 D：GPIO8/9/10
- STBY：GPIO11
- 后轮 B：GPIO12/13/14
- 右前轮 A：GPIO15/16/17
- BOOT：GPIO0，按下为低电平
