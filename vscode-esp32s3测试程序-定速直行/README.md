# 定速直行与四路传感器显示测试

小车上电后保持停止。短按一次 ESP32-S3 的 BOOT 键，小车按设定功率直行，达到设定时间后自动停止。运行期间再次按 BOOT 可以提前停止；停止后再次按 BOOT 可以重复测试。

LQ_TFT18SPIV33 屏幕会在上电后持续显示四路红外状态，从左到右为 OUT1、OUT2、OUT3、OUT4；`B` 表示黑色，`W` 表示白色。显示功能与直行控制同时运行，不需要连接电脑或打开 Monitor。

本工程只驱动左前轮和右前轮。后轮 B 通道的 GPIO12、GPIO13、GPIO14 始终强制为低电平，不会参与直行。

统一逻辑约定：每个轮子的逻辑 `+1` 都表示“使车体顺时针旋转”的轮向。根据实车电气极性，左轮和后轮底层反相，右轮不反相。直行前进的逻辑命令是左轮 `+1`、后轮 `0`、右轮 `-1`；最终两个前轮的电气输出均为 `-1`。

测试时先把小车架空确认三个轮子的动作方向，再放到开阔地面测试。

## 参数位置

打开 `main/main.c`，在文件顶部修改：

- `STRAIGHT_SPEED_PERCENT`：直行功率，范围 35～100，默认 50%。
- `STRAIGHT_DURATION_MS`：一次直行持续时间，单位毫秒，默认 3000 ms。
- `STRAIGHT_DIRECTION`：`1` 为当前前进方向，`-1` 为整体反向。

如果整车向后行驶，将 `STRAIGHT_DIRECTION` 从 `1` 改成 `-1`。如果车体明显跑偏，应分别校准左右电机功率，不能只靠提高总功率解决。

## 接口

- 左前轮 D：GPIO8/9/10
- STBY：GPIO11
- 后轮 B：GPIO12/13/14
- 右前轮 A：GPIO15/16/17
- BOOT：GPIO0，按下为低电平
- 红外 OUT1/OUT2/OUT3/OUT4：GPIO4/5/6/7
- TFT SCLK：GPIO39
- TFT SDI/MOSI：GPIO40
- TFT CS：GPIO41
- TFT DC/A0：GPIO42
- TFT RST：GPIO47
- TFT VCC、BL：3.3V（禁止接5V）
- TFT GND：ESP32 GND

显示屏不需要连接 MISO。显示屏、红外模块、电机驱动板和 ESP32-S3 必须共地。
