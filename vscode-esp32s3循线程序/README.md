# ESP32-S3 三轮全向小车循线项目

这是与电机、红外单项测试工程分开的独立 ESP-IDF 5.4.4 项目。

课程讲稿明确使用三轮全向底盘，因此程序没有套用普通两轮差速模型，而是将
“向前速度”和“绕车体中心转动速度”合成为右、左、后三个轮子的命令。

## 当前接线

| 功能 | GPIO |
|---|---:|
| 红外 IR1 / IR2 / IR3 / IR4 | 4 / 5 / 6 / 7 |
| 右轮 IN1 / IN2 / PWM | 8 / 9 / 10 |
| 电机公共 STBY | 11 |
| 左轮 IN1 / IN2 / PWM | 12 / 13 / 14 |
| 后轮 IN1 / IN2 / PWM | 15 / 16 / 17 |

## 控制方法

1. IR1～IR4必须沿车头横向从左到右排列。
2. 模块检测黑线时输出低电平，程序将黑线位置换算为误差：
   `-300、-100、+100、+300`。
3. 使用 PD 控制器将位置误差换算为转向命令。
4. 通过三全向轮速度合成得到右、左、后三轮命令。
5. 没有检测到黑线，或三个以上传感器同时检测到黑线时，立即停车。

其中三个及以上黑色通道暂时按“路口/宽线”处理并停车，后续确定赛道规则后
再添加通过路口的状态机。

## 第一次运行：只看日志，不驱动电机

源码默认设置为：

```c
#define ENABLE_MOTOR_OUTPUT 0
```

此时 GPIO11 保持低电平，三个轮子不会动作。烧录后打开串口监视器，用黑线在
四个探头下移动，检查日志中的：

```text
mask=0x... state=... error=... turn=... cmd[R,L,B]=[...]
```

建议先确认：

- 黑线在左侧时 `error` 为负；
- 黑线在右侧时 `error` 为正；
- 中间两个探头压线时 `error` 接近 0；
- 完全离开黑线时状态为 `LOST-STOP`。

如果 IR1～IR4 实际从右向左排列，把 `SENSOR_ORDER_SIGN` 改为 `-1`。

## 启用轮子前必须完成的校准

当前电机单项测试尚未完全确认，因此不要直接在地面开启循线。完成以下检查后，
把小车架空，再将 `ENABLE_MOTOR_OUTPUT` 改为 `1`：

1. 中线状态下，右轮命令为正、左轮命令为负、后轮为零时，小车趋势应指向前方。
2. 三轮收到同号命令时，底盘应原地旋转，而不是平移。
3. 如果某个轮方向相反，修改对应的 `*_ELECTRICAL_SIGN`。
4. 如果整体纠偏方向相反，修改 `STEERING_SIGN`。

## 初始参数

```c
#define BASE_SPEED_PERCENT 45
#define MIN_EFFECTIVE_DUTY_PERCENT 35
#define MAX_TURN_PERCENT 50
#define KP_NUMERATOR 12   // Kp = 0.12
#define KD_NUMERATOR 4    // Kd = 0.04
```

初次落地时建议继续保持低速并准备立即断开电机电源。确认方向正确后，再根据
摆动程度调整：摆动大则减小 Kp 或增加 Kd，转弯跟不上则增大 Kp 或降低基础速度。
