# ESP32-S3 摄像头四路黑白显示测试

这是从视觉巡线工程单独拆出的测试项目，只验证以下链路：

`JQ-CAM12-720D-V1摄像头 → ESP32-S3灰度处理 → 四路黑白判断 → LQ_TFT18SPIV33显示`

程序不会初始化或驱动电机和BOOT按钮。烧录并上电后会自动工作，不需要按BOOT，也不需要连接电脑才能刷新屏幕。HC-SR04会工作并在TFT上显示距离。

## 四路判断参数

- 控制图像：`160×120`灰度图。
- 采样行：图像底部 `y=112..119`，共8行。
- 黑色阈值：灰度小于110。
- 判黑条件：区域内至少10%的像素为黑。
- CH1：`x=[90,100)`，对应位图bit3。
- CH2：`x=[80,90)`，对应位图bit2。
- CH3：`x=[70,80)`，对应位图bit1。
- CH4：`x=[50,70)`，对应位图bit0。

以上范围直接沿用实车测试后已经确认正确的版本，没有重新调整左右顺序。

## 屏幕效果

TFT底部从左到右显示1、2、3、4路四个带黄色边框的区域，布局与原来正常工作的项目完全一致；上方 `D` 显示HC-SR04距离（cm）：

- 白色区域：该通道判断为白色地面。
- 黑色区域：该通道判断为黑线。
- 黄色边框始终保留，因此黑色状态不会与屏幕黑色背景混淆。

终端每500 ms输出一次，例如：

```text
CH1..CH4=WWBB counts=0/2/35/48 threshold=110 seq=120
```

其中`B=黑`，`W=白`，`counts`是四个采样窗口中的黑色像素数。

## 接线

| 模块 | 接线 |
|---|---|
| UVC摄像头 | D−=GPIO19，D+=GPIO20，5V，GND |
| TFT18 | SCLK=GPIO39，MOSI=GPIO40，CS=GPIO41，DC=GPIO42，RST=GPIO47 |
| HC-SR04 | TRIG=GPIO18，ECHO=GPIO21（ECHO必须分压至3.3V） |

三个电机可以保持原接线，但本程序不会控制它们。

## 使用步骤

1. 在VS Code中单独打开本文件夹。
2. 执行Build。
3. 执行Flash Device，烧录方式选择UART。
4. 复位后等待摄像头连接，TFT会自动刷新四路结果。
5. 如需查看日志，再运行Monitor Device；不运行Monitor不影响TFT工作。
