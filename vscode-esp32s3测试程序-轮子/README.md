# ESP32-S3 三轮电机交互测试

本项目以已经验证成功的 Arduino `A/B/D/S` 单轮测试逻辑为基础，增加了：

- 三个电机分别正转和反转；
- 10%～100% PWM调速；
- 三个电机同时正转或反转；
- 换向前关闭PWM 50ms，降低H桥换向冲击；
- 20kHz PWM，避免此前5kHz产生明显可听啸叫。

## GPIO分配

| 物理位置 | 驱动通道 | IN1 | IN2 | PWM/使能 |
|---|---|---:|---:|---:|
| 左前轮 | Motor D | GPIO8 | GPIO9 | GPIO10 |
| 后轮 | Motor B | GPIO12 | GPIO13 | GPIO14 |
| 右前轮 | Motor A | GPIO15 | GPIO16 | GPIO17 |
| 公共使能 | STBY | GPIO11 | — | — |

GPIO4～7为红外循迹模块保留，本程序不配置、不读取。

## 安全要求

1. 烧录前把小车架空，保证三个轮子都不接触桌面。
2. 电机使用驱动板电源，不能由ESP32的3.3V引脚供电。
3. ESP32和电机驱动板必须共地。
4. 三轮同时测试前先逐个验证正反转，并准备立即输入 `S` 停止。

## 串口命令

烧录后打开 `Monitor Device`，点击终端并输入命令；是否需要回车取决于当前
串口监视器输入方式，输入后无响应时再按回车。

| 命令 | 功能 |
|---|---|
| `A` / `a` | Motor A（右前轮）正转 / 反转 |
| `B` / `b` | Motor B（后轮）正转 / 反转 |
| `D` / `d` | Motor D（左前轮）正转 / 反转 |
| `F` / `R` | 三个电机同时正转 / 反转 |
| `S` | 停止所有电机 |
| `+` / `-` | 当前速度增加 / 减少10% |
| `1`～`9` | 将当前速度直接设为10%～90% |
| `0` | 将当前速度设为100% |
| `H` | 重新显示帮助 |

默认速度为100%。低于30%时，部分电机可能因启动转矩不足而只发声不转动。
三轮同方向旋转只是驱动通道测试，不表示三轮全向底盘会直线前进。
