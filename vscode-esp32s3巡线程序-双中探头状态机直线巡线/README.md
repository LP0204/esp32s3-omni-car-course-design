# 双中探头状态机巡线（丢线左转 90°）

本工程让小车沿黑线自动纠偏。短按 ESP32-S3 的 BOOT 键开始，再按一次停止；烧录完成后不需要连接电脑，也不需要打开 Monitor。正常巡线只驱动左右前轮；黑线消失（四路有效采样全白）时，自动启用三轮原地左转 90°，转完后低速重新捕获黑线并继续巡线。

后轮 GPIO12/13/14 在正常巡线时锁止，仅在定角转弯状态启用。LQ_TFT18SPIV33 会持续显示四路红外结果，从屏幕左到右为 OUT1、OUT2、OUT3、OUT4，`B` 表示黑色，`W` 表示白色。

## 传感器物理顺序

从车头向前看，实际物理位置从左到右为：

| 位置 | 模块输出 | GPIO | black_mask 位 |
|---|---|---:|---:|
| 最左 | OUT4 | 7 | bit3 |
| 左中 | OUT3 | 6 | bit2 |
| 右中 | OUT2 | 5 | bit1 |
| 最右 | OUT1 | 4 | bit0 |

模块原始输出为低电平表示黑色。程序内部把黑色统一转换成 `1`，再进行判断。

## 状态机逻辑

每次控制先对每个通道连续采样 5 次并做多数表决；除“四路全白”外，新的识别结果还要连续出现 2 个控制周期才会生效，避免反光、接触不良或黑白边缘抖动导致电机频繁跳变。全白单独走快速停车路径。

1. `TRACK_CENTER`：OUT3、OUT2 都为黑。认为黑线位于车体中央，左右轮分别以基础功率前进。
2. `CORRECT_LEFT`：只有左中 OUT3 为黑。说明黑线在车体左侧，降低左轮、提高右轮，柔和向左纠偏。
3. `CORRECT_RIGHT`：只有右中 OUT2 为黑。说明黑线在车体右侧，提高左轮、降低右轮，柔和向右纠偏。
4. `RECOVER_LEFT/RIGHT`：只有在最左或最右探头确实检测到黑线时，才使用较大的功率差进行强纠偏。
5. `TURN_LEFT`：四路经过 5 次多数采样后全白时，立即进入定时左转状态。三轮按与“顺时针逻辑 +1”相反的方向同时转动；默认目标为左转 90°，转弯期间忽略传感器变化。
6. `REACQUIRE_LINE`：定角时间结束后，停止三轮转动，改用两个前轮以 35% 功率低速前进，等待任意有效探头图样重新出现；重新看到黑线后回到对应的巡线纠偏状态。
7. `FAULT_STOP`：转弯后超过 300 ms 仍未重新捕获黑线，或出现交叉/矛盾图样时停车。重新把中间探头放到黑线上，再按 BOOT 可重新开始。

传感器每次先做 5 次多数表决，已经过滤了单次采样毛刺；全白结果不等待普通状态机的两周期确认，避免丢线后的额外直行过冲。由于定角旋转是开环时间估算，实际角度仍需根据地面、供电和负载标定。

这种逻辑不假设两个电机同功率就同转速：传感器只要观察到单侧偏移，状态机就会改变左右轮功率把车拉回中央。同时仍保留左右基础功率的独立标定，用来减小长期单向纠偏和蛇形摆动。

## 首次调试顺序

1. 先架空小车，确认按 BOOT 后只有两个前轮向前，后轮不动；再次按 BOOT 能停车。
2. 把黑线依次放在四个探头下，确认屏幕相应通道显示 `B`，白底时显示 `W`。
3. 把中间两个探头放在黑线上再按 BOOT。程序不允许在四路全白或图样矛盾时启动。
4. 先架空模拟四路全白，确认三轮向左转，约 720 ms 后进入低速重新捕获状态；再次按 BOOT 可以随时停止。
5. 小车向右偏时，应进入 `CORRECT_LEFT` 并向左回线；如果实车纠偏方向恰好相反，只把 `STEERING_SIGN` 从 `1` 改为 `-1`。
6. 先用低速短距离测试，再逐步调高功率和纠偏量。

## 可调参数

参数都在 `main/main.c` 顶部：

- `LEFT_BASE_POWER_PERCENT`：左前轮基础功率，默认 50%。
- `RIGHT_BASE_POWER_PERCENT`：右前轮基础功率，默认 50%。
- `SOFT_CORRECTION_PERCENT`：只有一个中间探头为黑时的功率差，默认 15%。
- `HARD_CORRECTION_PERCENT`：外侧探头确实检测到黑线时的强纠偏功率差，默认 30%。
- `STEERING_SIGN`：纠偏方向，默认 `1`；实车方向完全相反时改成 `-1`。
- `LINE_LOST_TURN_ANGLE_DEG`：丢线后的目标角度，负数为左转；当前为 `-90.0f`。
- `TURN_POWER_PERCENT`：三轮定角转弯功率，默认 45%。
- `TURN_MS_PER_DEGREE`：每旋转 1° 的时间，默认 `8.0 ms/°`；实车转角不足就增大，转角过大就减小。
- `REACQUIRE_POWER_PERCENT`：转弯结束后重新找线的前轮功率，默认 35%。
- `REACQUIRE_TIMEOUT_MS`：转弯后等待重新捕获黑线的最长时间，默认 300 ms；超时停车。

若小车长期向右偏，先稍微降低右轮基础功率或提高左轮基础功率；长期向左偏则反过来。基础功率每次只改 2%～3%，不要一次大幅调整。若左右来回摆动，先减小 `SOFT_CORRECTION_PERCENT`；若回线太慢，再增大它。

## 接口

- 左前轮 D：GPIO8/9/10
- STBY：GPIO11
- 后轮 B：GPIO12/13/14（始终锁止）
- 右前轮 A：GPIO15/16/17
- BOOT：GPIO0，按下为低电平
- 红外 OUT1/OUT2/OUT3/OUT4：GPIO4/5/6/7
- TFT SCLK：GPIO39
- TFT SDI/MOSI：GPIO40
- TFT CS：GPIO41
- TFT DC/A0：GPIO42
- TFT RST：GPIO47
- TFT VCC、BL：3.3V（禁止接 5V）
- TFT GND：ESP32 GND

显示屏不需要连接 MISO。显示屏、红外模块、电机驱动板和 ESP32-S3 必须共地。
