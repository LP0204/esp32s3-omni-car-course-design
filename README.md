# ESP32-S3 Omni Car Course Design

清华大学“电子设计技术基础”小学期课程工程。项目基于 ESP32-S3 和三轮全向
底盘，逐步完成硬件单项测试、循迹、避障以及后续扩展功能。

## 工程目录

| 目录 | 内容 |
|---|---|
| `ir-sensor-test` | 四路红外循迹传感器黑白识别测试 |
| `motor-test` | 三个电机的统一逻辑方向、转速和同时运行测试 |
| `fixed-angle-turn-test` | 三轮原地定角旋转及时间标定测试 |
| `tft18-display-test` | TFT18 显示屏与四路黑白状态显示测试 |
| `ir-line-follow` | 两个中间探头主导的红外状态机巡线，丢线后左转 90° 并重新捕获 |
| `ultrasonic-avoidance` | HC-SR04 超声波测距与避障程序 |
| `camera-gray-viewer` | 720p UVC 取图、80×60 灰度串流及 macOS 浏览器实时预览 |
| `camera-sensor-display` | 摄像头四路虚拟传感器、TFT18 状态与距离显示测试 |

除 TFT18 独立测试工程外，其他需要显示传感器状态的工程均内置同一套
`LQ_TFT18SPIV33` 显示模块；显示屏断开时不影响电机和传感器控制逻辑。

## 统一接口定义

| 功能 | GPIO / 通道 |
|---|---|
| 红外 OUT4 / OUT3 / OUT2 / OUT1（从车头看由左到右） | 7 / 6 / 5 / 4 |
| 左前轮 | GPIO8 / 9 / 10，驱动板 D 通道 |
| 后轮 | GPIO12 / 13 / 14，驱动板 B 通道 |
| 右前轮 | GPIO15 / 16 / 17，驱动板 A 通道 |
| 电机公共 STBY | GPIO11 |
| 巡线启动/停止按钮 | GPIO0（开发板 BOOT 键，按下为低电平） |
| HC-SR04 TRIG / ECHO（ECHO 必须分压） | GPIO18 / GPIO21 |

## 接线情况2：摄像头与云台

| 功能 | GPIO / 电源 |
|---|---|
| ESP-Claw 专用摄像头（摄像头/麦克风/喇叭三合一）USB D− / D＋ | GPIO19 / GPIO20 |
| 摄像头供电 | 5V + GND |
| 云台左右舵机 | GPIO4 |
| 云台上下舵机 | GPIO5 |
| 空闲 | GPIO6 / GPIO7 |

接线情况2取消了原四路红外传感器；电机和 STBY 接口保持不变。摄像头的 D−、D＋
必须分别接 GPIO19、GPIO20，且摄像头与 ESP32-S3 共地。

## 电机方向约定

所有电机工程统一采用“车体逻辑方向”，不再把驱动芯片 IN1/IN2 的电平直接
称为正转或反转：

- 单轮命令 `+1`：该轮沿使车体顺时针旋转的方向运动；
- 单轮命令 `-1`：该轮沿使车体逆时针旋转的方向运动；
- 右前轮当前的电气 `+1` 为实车基准。

### 实车电气极性

| 轮子 | 驱动通道 | GPIO | `electrical_sign` |
|---|---|---|---:|
| 左前轮 | D | 8/9/10 | -1 |
| 后轮 | B | 12/13/14 | -1 |
| 右前轮 | A | 15/16/17 | +1 |

因此逻辑 `+1,+1,+1` 会转换为电气 `-1,-1,+1`，车体顺时针原地旋转。

### 底盘运动合成

| 运动 | 左前轮逻辑值 | 后轮逻辑值 | 右前轮逻辑值 |
|---|---:|---:|---:|
| 前进 | +1 | 0 | -1 |
| 后退 | -1 | 0 | +1 |
| 顺时针旋转 | +1 | +1 | +1 |
| 逆时针旋转 | -1 | -1 | -1 |

后续程序的运动控制层只使用这套逻辑值；各通道的实际 IN1/IN2 电平由
`electrical_sign` 在底层转换。

## 开发环境

- ESP32-S3-DevKitC-1
- ESP-IDF 5.4.4
- Visual Studio Code + Espressif IDF 扩展
- macOS

每个子工程均为独立 ESP-IDF 工程，应在 VS Code 中单独打开对应工程根目录。
构建产物、自动生成的 `sdkconfig` 和本机编辑器配置不纳入版本管理。
